# TRANPASS

Google Apps Script (GAS) 製のパスワード管理アプリ。アカウント・パスワードを
**AES-256 で暗号化**して Google Drive に保存し、PC / Mac / iPhone のブラウザから
安全に閲覧・コピーできます。

## 主な機能

- 🔐 **AES-256-CTR + HMAC-SHA256**（Encrypt-then-MAC）でVaultを暗号化
- 🔢 **覗き見対策ログイン**：1〜9をシャッフルした3×3グリッドから、設定した4桁を選択
- 🗂 **カテゴリー**（選択式・設定画面で追加/削除/並べ替え）
- 👤 **サブアカウント**：銀行/証券のログインパスワードと取引パスワードなどを複数保持
- 💳 **クレジットカード**：カード番号 / 有効期限 / セキュリティコード
- 📝 **メモ**機能
- 🔍 **検索** ＋ 各項目の **📋コピーボタン**（パスワード等は60秒後に自動クリア）
- 🔒 失敗5回で5分ロック、PIN変更、暗号化バックアップ

## セキュリティ設計

| 項目 | 内容 |
|------|------|
| アクセス | Webアプリは「自分のみ」（`appsscript.json` の `access: MYSELF`） |
| 暗号鍵 | 32バイトのマスターキーを初回自動生成し Script Properties に保管 |
| 認証 | 4桁PIN（1〜9）。ソルト＋ストレッチ（SHA-256 ×2000）でハッシュ保存 |
| データ | Drive の `TRANPASS/tranpass.enc` に暗号文のみ保存（平文は保存しない） |
| セッション | ログイン後トークンを UserCache に保持（30分） |

> マスターキーはあなたのGASプロジェクト（＝あなたのGoogleアカウント）に紐づきます。
> アプリ経由でのみ復号され、Drive上のファイルは暗号化された状態です。

## ファイル構成

```
src/
├── appsscript.json   マニフェスト（スコープ / Webアプリ設定）
├── Code.gs           認証・CRUD・Drive入出力
├── Crypto.gs         AES-256-CTR + HMAC + 乱数/バイト操作
├── Test.gs           セルフテスト（runSelfTest）
├── Index.html        画面構成
├── Style.html        CSS（モバイル対応）
└── Script.html       クライアントJS
```

## セットアップ

### 方法A：手動（GASエディタにコピペ）

1. <https://script.google.com> で新規プロジェクトを作成
2. `Code.gs` / `Crypto.gs` / `Test.gs` をスクリプトファイルとして作成し、`src/` の内容を貼り付け
3. `Index.html` / `Style.html` / `Script.html` を **HTMLファイル**として作成し貼り付け
   （ファイル名は拡張子なしで `Index` `Style` `Script`）
4. プロジェクト設定 → 「`appsscript.json`（マニフェスト）を表示」を有効化し、`src/appsscript.json` の内容に置き換え
5. （任意）エディタで `runSelfTest` を実行し、ログがすべて `[OK]` になることを確認
6. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
7. 初回は権限承認が必要です。発行されたURLを開く
8. 初回アクセス時に4桁PIN（1〜9）を設定 → 以降はそのPINでログイン

### 方法B：clasp（CLI）

```bash
npm install -g @google/clasp
clasp login
clasp create --type webapp --title "TRANPASS" --rootDir ./src
# 生成された scriptId を src/.clasp.json に設定（.clasp.json.example 参照）
clasp push
clasp deploy
```

その後、GASエディタの「デプロイを管理」からウェブアプリ設定（実行：自分 / アクセス：自分のみ）を確認してください。

## 使い方

- **追加**：一覧右下の ＋ → 「通常」か「クレジットカード」を選んで入力
- **サブアカウント**：通常入力画面で「＋ サブアカウントを追加」
- **検索**：上部の検索ボックス（名称・アカウント・カテゴリー・メモが対象）
- **コピー**：各値の 📋 ボタン。パスワード/セキュリティコードは伏字＋👁で一時表示
- **設定**（⚙）：カテゴリー編集 / PIN変更 / 暗号化バックアップ作成
- **ロック**（🔒）：すぐにログイン画面へ戻す

## バックアップと復元

- 設定画面の「暗号化バックアップを作成」で `tranpass-backup-YYYYMMDD-HHmmss.enc` を生成します。
- これらは同じプロジェクトのマスターキーでのみ復号できます。プロジェクト（スクリプト）自体も
  Apps Script のバージョン管理や `clasp` で別途バックアップしておくことを推奨します。

## 注意

- PINを忘れた場合、PIN自体のリセットは Script Properties の `PIN_HASH` / `PIN_SALT` を
  削除すれば再設定できます（データはマスターキーが残っていれば保持されます）。
- `MASTER_KEY` を削除・変更すると既存データは復号できなくなります。**絶対に削除しないでください。**
